# 🏃‍♂️ 나만 아니면 돼 (Not Me)
> "폭탄 목걸이를 찬 채 달리는 두 생존자의 치열한 눈치 싸움."

## 📝 프로젝트 개요 (Overview)
* **장르**: 1vs1 횡스크롤 하이퍼 러닝 액션
* **플랫폼**: Android / iOS (Mobile)
* **개발 엔진**: Unity 2D
* **개발 기간**: 2026.01.06 ~ 2026.02 (3개월)
* **한 줄 소개**: 더 빨리 탈출한 쪽만 살려준다는 제안을 받은 두 생존자의 목숨을 건 레이싱 게임입니다.

---

## 🎬 시놉시스 (Story)
급전이 필요해 '고수익 임상 알바'에 지원한 두 친구. 하지만 그곳은 불법 생체 실험실이었습니다.
연구소장은 두 사람의 목에 **폭탄 목걸이**를 채우며 제안합니다.

> **"결승선에 먼저 도착하는 단 한 명만 살려주겠다."**

늦게 도착한 자의 목걸이는 폭발합니다. 이제 살기 위한 질주가 시작됩니다.

---

## 🎮 핵심 기능 (Key Features)

### 1. 죽지 않는 '무한 레이싱' (Infinite Racing)
* 기존 러닝 게임의 '체력(HP) 소진 시 게임 오버' 시스템을 삭제했습니다.
* 장애물에 부딪히면 **속도 페널티(경직)**를 받으며, 승부는 오직 **'누가 먼저 도착하느냐'**로 결정됩니다.

### 2. 조작의 단순화 (2-Button Action)
* 복잡한 슬라이드 키를 삭제하고 **[JUMP]**와 **[ITEM]** 단 두 개의 버튼에 집중했습니다.
* **최대 2단 점프**를 통해 높낮이와 타이밍만으로 장애물을 돌파하는 섬세한 컨트롤을 요구합니다.

### 3. 저스트 회피 (Just Dodge) & 리스크 테이킹
* 장애물에 충돌하기 직전 아슬아슬하게 피하면 **'순간 가속(Boost)'**과 **'아이템 게이지 대량 충전'** 효과를 얻습니다.
* 안전하게 갈 것인가, 위험을 감수하고 역전을 노릴 것인가? 매 순간 선택해야 합니다.

### 4. 전략적 아이템 시스템 (Strategic Items)
* **실험실 테마**의 아이템으로 상대를 직접 타격하거나 방해합니다.
* **1등 견제**: 화면 노이즈(Glitch Screen) 등으로 선두의 실수를 유도.
* **2등 역전**: 중력 족쇄, 강제 가속(Overload) 등으로 상대를 멈춰 세움.

## 🛠️ 기술적 도전 (Technical Challenges)
* **동기화 (Synchronization):** Photon(또는 사용한 네트워크 툴)을 활용한 1vs1 실시간 위치 동기화.
